# Architecture Decision Records

One file per decision that is **expensive to reverse**, **was genuinely contested**, or
**will look wrong to someone who doesn't have the context**. Everything else belongs in the
numbered documents.

Format: `NNNN-kebab-title.md` — Context · Decision · Consequences · Alternatives · Status.
Status is `Proposed` → `Accepted` / `Rejected` → `Superseded by NNNN`. An ADR is never edited
after acceptance; it is superseded by a new one, so the reasoning trail stays intact.
